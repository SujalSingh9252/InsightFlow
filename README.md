# 📌 Overview

**InsightFlow** is an AI-powered data analysis platform designed to simplify the complete machine learning workflow through an intuitive Streamlit interface.

The platform enables users to upload datasets, perform exploratory data analysis, visualize patterns, train machine learning models, evaluate their performance using comprehensive metrics, and leverage deep learning models for image classification—all from a single application.

The objective of this project is to bridge the gap between raw data and meaningful business insights by providing an interactive, user-friendly analytics environment.

# ✨ Key Features

### 📊 Intelligent Data Analysis

* Upload CSV datasets
* Dataset preview
* Data preprocessing
* Missing value handling
* Statistical summaries
* Feature exploration

### 📈 Interactive Visualizations

* Correlation Heatmaps
* Distribution Plots
* Scatter Plots
* Histograms
* Box Plots
* Plotly Interactive Charts

### 🤖 Machine Learning

Supports multiple supervised learning workflows including

* Classification
* Regression

Includes automatic evaluation using metrics such as

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC
* Matthews Correlation Coefficient
* MAE
* MSE
* RMSE
* R² Score
* Explained Variance

### 🧠 Deep Learning Module

The platform integrates a TensorFlow/Keras model capable of image classification through an easy-to-use upload interface.

Features include

* Image Upload
* Automatic Image Preprocessing
* Deep Learning Prediction
* Class Identification

### 📉 Model Evaluation

Provides comprehensive evaluation through

* Confusion Matrix
* Classification Report
* ROC Curve
* Precision-Recall Curve
* Regression Metrics
* Performance Comparison

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/SujalSingh9252/InsightFlow.git
```

Move to the project directory

```bash
cd InsightFlow
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run Main.py
```
